# Requirement Analysis

## Project Title
AI WeatherWise API

## Functional Requirements

1. The system should accept a city name from the user.
2. The system should find the location of the requested city.
3. The system should retrieve current weather information.
4. The system should provide temperature, humidity and wind speed.
5. The system should identify the current weather condition.
6. The system should provide smart weather advice.
7. The system should handle invalid or unavailable city requests.

## Non-Functional Requirements

- The API should provide a fast response.
- The API should return data in JSON format.
- The API should handle errors properly.
- The application should be easy to use and maintain.

## Technologies Required

- Node.js
- Express.js
- JavaScript
- Open-Meteo Weather API
- MongoDB
- GitHub
